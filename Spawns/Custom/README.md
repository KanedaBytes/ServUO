# Spawns/Custom

Custom XmlSpawner2 spawn XML. Import with `[XmlLoad Spawns/Custom` (the command recurses
directories). `<UniqueId>` is the identity, so a re-import replaces a spawner rather than
stacking a second one.

Kept separate from the stock `Spawns/` files so `[XmlLoad Spawns` and world regeneration do not
mix custom content with upstream spawns.
